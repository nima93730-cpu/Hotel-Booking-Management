# 🏨 Hotel Booking Management System

A modern and responsive **Hotel Booking Management System** built with **React, TypeScript, Tailwind CSS, and shadcn/ui**.

The application is designed to provide a simple and user-friendly platform for browsing hotel rooms, checking availability, making reservations, and managing hotel bookings.

## 📌 Project Overview

The Hotel Booking Management System helps simplify the hotel reservation process through a modern web interface.

Users can explore available rooms, view important room information, select their preferred dates, and manage their bookings. The project also provides a structured interface that can be extended with additional hotel management features in the future.

## ✨ Features

* 🏨 Modern hotel booking interface
* 🔎 Search and browse available rooms
* 🛏️ View room details and facilities
* 📅 Select check-in and check-out dates
* 👥 Manage guest information
* 💳 Booking and reservation interface
* 📋 View and manage reservations
* 📱 Responsive design for desktop, tablet, and mobile
* 🎨 Modern UI using Tailwind CSS
* 🧩 Reusable components using shadcn/ui
* ⚡ Fast and interactive React interface
* 🔷 TypeScript for better type safety

## 🛠️ Technologies Used

* **React** – Frontend JavaScript library

* **Tailwind CSS** – Utility-first CSS framework

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/hotel-booking.git
```

### 2. Navigate to the project

```bash
cd hotel-booking
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.

## 🎯 Main Modules

### 🏠 Home Page

Provides an overview of the hotel and allows users to begin searching for rooms.

### 🛏️ Room Management

Displays available rooms with information such as:

* Room type
* Price
* Capacity
* Facilities
* Availability
* Room images

### 📅 Booking Management

Allows users to select dates and make hotel reservations.

### 👤 Guest Management

Stores and manages basic guest information required for reservations.

### 📋 Reservation Management

Provides an overview of current and previous bookings.
